# Четыре и восемь слотов генерации

Статус: завершено для всех трёх моделей. Полные данные — в [таблице](TABLE.md).

Восемь слотов ускорили обслуживание восьми коротких запросов. Медиана времени
всей волны после прогрева:

| Модель | Четыре слота, с | Восемь слотов, с | Прирост суммарной скорости |
|---|---:|---:|---:|
| MedGemma 4B | 10,29 | 6,40 | 61% |
| MedGemma 1.5 4B | 10,35 | 6,46 | 60% |
| MedGemma 27B | 67,05 | 40,11 | 67% |

При одном или четырёх клиентах сопоставимого выигрыша нет. Восемь слотов —
кандидат для увеличения пропускной способности коротких запросов. Это не
подтверждает готовность режима 8/8/8 при общей нагрузке на единственный GPU.

Сравниваются `max_num_seqs=4` и `8`. Каждый профиль получает 1, 4 и 8
одновременных HTTP-запросов. Вход содержит около 1500 токенов, выход — ровно
128 токенов. Одна прогревочная волна исключается, затем измеряются три волны.
Ревизия весов, BF16, бюджет 2048, контекст 16384 и размер KV-кеша сохраняются.

При четырёх слотах восемь клиентов обслуживаются с ожиданием внутри движка.
Это тест vLLM напрямую. Рабочий inference backend имеет отдельный лимит 4+1;
этот лимит в исследовании не меняется. Восемь слотов ещё не означают готовность
рабочего API принимать восемь генераций.

Для внедрения слоты задаются в `deploy/inference/profiles/dgx-spark.json`
полем `maxNumSeqs`. Лимиты сервиса находятся в
`deploy/dgx-spark/config/server.json`: `max_concurrent_requests` и
`max_waiting_requests`. Размер очереди и её тайм-аут выбираются отдельно;
увеличение слотов не требует автоматически делать очередь неограниченной.

Суммарная скорость — число выходных токенов всех клиентов, делённое на время
всей волны. Время отдельного ответа и TTFT указаны отдельно. Эти величины
нельзя подменять скоростью одного токенового потока.

Две другие модели загружены, но не генерируют. Режим 8/8/8 не проверяется.
Это синтетическая проверка производительности, а не оценка медицинского качества.

Фактура: `*/{baseline,seq8}/results.jsonl`, параметры в соседних `plan.json`.
Сводные данные находятся в [summary.json](summary.json). Полные команды
контейнеров и время их запуска находятся в `../runs/`.
